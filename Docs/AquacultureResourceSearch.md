# Aquarium / sea-pen resource discovery (in progress)

Search: 2026-09-26, before authoring this category. These are candidates, not
runtime assets or an accepted home/aquaculture experience.

- [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit): individual
  official page links CC0 1.0. The inspected 2.0 archive's License.txt explicitly
  allows commercial use, with optional attribution, creation 2018-10-20 16:21.
  Its 140 GLB entries contain cabinets but no aquarium. A cabinet may serve as
  a modified base; a functional glass tank still needs a suitable source/design.
- [Kenney Watercraft Kit](https://kenney.nl/assets/watercraft-kit): official CC0
  page and included 2.1 license agree, creation 2024-04-19 11:37. The archive
  contains buoy.glb and buoy-flag.glb, candidates for a modified pen float. No
  boat in this pack is automatically accepted as a NeonCity hero vehicle.
- [Fish Tank by J-Toastie](https://poly.pizza/m/FLnlsLbY2s) and
  [Fish Tank by Chris Ross](https://poly.pizza/m/2Rb9zxgkDEM) identify Creative
  Commons Attribution on their individual pages. Exact version/download review
  could not be completed: local requests returned HTTP 403. No asset was
  downloaded; attribution/terms must be resolved before adoption. This is a
  category-specific access block, not a claim that all Internet search failed.
- [Public Aquarium and Marine Centre](https://3dassets.dev/packs/public-aquarium-and-marine-centre)
  declares CC0 1.0 and discloses AI-authored geometry. It describes large public
  wall modules rather than a small home aquarium. Not downloaded or accepted;
  style/geometry inspection would still be required.

Official archives and license evidence are retained under
ArtSource/External/Kenney/{FurnitureKit,WatercraftKit}. ZIP signatures, bounded
sizes, archive paths and contained license text were checked before any geometry
extraction; no executable/installer/script is run. Actual source download URLs,
UTC download time and SHA256 are in each provenance.json. Final category
decisions and full adopted-asset manifest entries follow actual review.
